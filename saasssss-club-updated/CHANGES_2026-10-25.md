# ClubX — 2026-10-25: free / paid / contact plan step + app download in onboarding and every club

Files are in their original paths (copy over `saasssss-club-updated/`). No new dependency, no migration.

## 1. Plan step (onboarding, step 5 "Choisir un plan")
- Two clear choices: **Essai gratuit — 14 jours** (no card, no payment) or **Plan payant**.
- Paid → **Stripe Checkout** when Stripe is configured and the country is not Tunisia. The owner can still pick
  "Nous contacter / payer sans carte".
- Paid but Stripe not available (not configured, or Tunisia) → the page says so and shows the **contact** form
  (payment method + phone/WhatsApp). The club is created closed, a PENDING request goes to Super Admin, and it is
  activated only after payment is verified (existing manual-payment flow).
- Server: `lib/payments/availability.ts` (`isStripeConfigured` = `STRIPE_SECRET_KEY` + `STRIPE_WEBHOOK_SECRET`).
  `GET /api/payments/country` now also returns `stripeEnabled`. `create-club` refuses a card signup with
  `400 STRIPE_UNAVAILABLE` BEFORE creating anything; the page then switches to the contact route.
- "Free plan" = the 14-day trial. A permanent free plan does not exist (the server still refuses priceMonthly <= 0).

## Publish the app so the buttons appear (nothing shows until a real APK is configured)
1. `clubx-mobile/eas.json`: replace `https://REPLACE-WITH-YOUR-APEX-DOMAIN` (profiles `apk` and `production`) with your real https domain.
2. In `clubx-mobile`: `npm i -g eas-cli`, `eas login`, `eas build -p android --profile apk` (let EAS create the keystore). Download the .apk.
3. Install it on a real Android phone and test login + club search.
4. GitHub → your repo → Releases → new release `v1.0.0` → attach the .apk → copy the asset link.
5. SHA-256 (PowerShell): `Get-FileHash .\clubx.apk -Algorithm SHA256`
6. Vercel env vars, then redeploy: `ANDROID_APK_URL`, `ANDROID_APK_VERSION=1.0.0`, `ANDROID_APK_SHA256`, `ANDROID_APK_SIGNED=true`, `ANDROID_APK_RELEASE_NOTES=Première version|Réservations|Notifications`.
7. Later: Google Play (25 USD once): `eas build -p android --profile production` + `eas submit`, then `ANDROID_PLAY_URL`.
8. iPhone: works now as a web app (Add to Home Screen, steps on /download). App Store / TestFlight needs an Apple Developer account (99 USD/year); then set `NEXT_PUBLIC_IOS_TESTFLIGHT_URL`.
9. For card payments: set BOTH `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET`. Without them the paid option shows "contact us".
