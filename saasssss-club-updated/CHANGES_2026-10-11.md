# ClubX update 2026-10-11 — speed, design polish, 8 new 3D models

Copy every file over the same path in `saasssss-club-updated`. No new npm packages, no migration.

## Speed
- `lib/public-settings-payload.ts` (new) + `app/layout.tsx` + `context/ClubSettingsContext.tsx`: club settings are resolved on the server and handed to the page, so the homepage renders on the first response (no blank page, no duplicate /api/settings/public call).
- `lib/public-cache.ts` (new): 5s fresh / 60s stale-while-revalidate cache for plans, coaches, schedule, promotions, page content (per club). Used by the 5 public API routes.
- `lib/auth.ts`: after any authenticated write (POST/PUT/PATCH/DELETE) the club's public cache is flushed (Next `after()`), so admins see their change at once. Other server instances converge within ~5s.
- `lib/public-fetch.ts` (new): browser-side shared request + 4s memo. Used by CoachesSection, PricingSection, CalendarPreview, usePublicPromotions, useEditableContent (admin preview events force a refresh).
- `components/themes/ScrollCompanion.tsx`: second WebGL context only on capable devices, only after idle.
- Tab-visibility settings refresh throttled to once per 30s.

## 3D
- 8 new models in `components/themes/hero3d/models.ts` + `lib/website-themes.ts`: trophy, stopwatch, protein-shaker, yoga-mat, plyo-box, jump-rope, lotus, gym-rings (16 total). Picker grid scrolls.
- Default model changed: Luxury -> trophy, Neon -> stopwatch (only for clubs with no saved choice).
