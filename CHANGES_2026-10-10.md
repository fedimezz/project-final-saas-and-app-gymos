# ClubX — changes 2026-10-10

## 1. Logout (root cause + fix)
- Cause: `logout()` fired `POST /api/auth/logout` without waiting and the page navigated at once → the browser cancelled the request, the httpOnly cookie survived, `/api/auth/session` signed the user back in (login page auto-redirected to "Mon espace").
- Fix: `lib/logout-client.ts` (tested sequence) — wipe client state → AWAIT server (keepalive, retry once, verify session is gone) → hard `location.replace`. Server route always clears the cookie (even if audit/DB fails), returns `redirectTo` from the VERIFIED role (SUPER_ADMIN → /platform/login), `Cache-Control: no-store`. A late in-flight session check can no longer restore the user.
- Files: context/AuthContext.tsx, lib/logout-client.ts, app/api/auth/logout/route.ts, app/api/auth/session/route.ts, Navbar, AdminSidebar, PlatformSidebar, DashboardHeader, DashboardSidebar, dashboard/page.tsx, dashboard/settings/page.tsx.

## 2. Horizontal pricing
- New `components/pricing/PlanRowCard.tsx` (+ `PlanRowList`): 3 aligned columns on desktop (identity | features | price + button), stacked on mobile. Used by: club home PricingSection, /offres, member PlansList, SaaS landing Pricing, /admin/billing.
- New `lib/saas-plan-features.ts` (shared feature lines).

## 3. Custom 3D model
- DB: `ClubHeroModel` (prisma/migrations/20261010000100_club_hero_model) — **run `prisma migrate deploy`**.
- API: `/api/admin/hero-model` (OWNER only: GET/POST/PUT/DELETE, club from session, rate-limited, website-lock aware), `/api/hero-model` (public, club from HOST, ETag/immutable cache, nosniff + sandbox CSP).
- Validation (`lib/hero-model.ts`, same rules client + server): real-byte GLB/glTF checks, self-contained only, no Draco/meshopt/KTX2, triangle/texture caps, size cap (default 4 MB, `HERO_MODEL_MAX_BYTES`).
- UI: `components/admin/CustomHeroModelPanel.tsx` + HeroModelPicker ("Mon modèle 3D", "Aucun objet 3D") in /admin/appearance.
